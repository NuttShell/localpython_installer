Python Embed Installer

Drops a self-contained, embeddable Python next to your project — pip and your packages included. No system install, no PATH changes, nothing left behind when you delete the folder.

Quick start — open Windows PowerShell where you want Python installed, and paste this command:

Windows PowerShell
—□×
PS C:\Users\you>

Add -PyVer 3.14.1 -Arch amd64 to skip the version picker.

or download, unzip and run on your PC:

Download latest release All releases

What it does

  1. Downloads an embeddable Python build for your version and architecture
  2. Installs pip (falls back to a wheel if get-pip is unreachable)
  3. Installs your packages — requirements.txt, or PyInstaller by default
  4. Leaves it all in one folder — nothing touches the rest of your system

Two ways to run it

get_con.cmd — console
Scriptable: command-line flags, pyconfig.json, CI-friendly.
get_win.cmd — GUI
Point-and-click version picker, progress bar, no terminal required.
