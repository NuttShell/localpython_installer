# Python Embed Installer

Самораспаковывающийся установщик **Embeddable Python** для Windows с интерактивным выбором версии, автоматической установкой `pip` и пакетов.

> **Embeddable Python** — это минимальная portable-сборка интерпретатора от python.org, не требующая установки в систему и не вносящая изменений в реестр Windows.

---

## ✨ Возможности

- **Один файл** — никаких внешних зависимостей.
- **Интерактивный выбор** — сканирует `python.org`, показывает доступные версии и архитектуры (`win32` / `amd64`).
- **Автоустановка pip** — сначала пытается поставить через `get-pip.py`, при неудаче автоматически скачивает и распаковывает `pip` wheel с PyPI.
- **Установка пакетов** — после установки pip автоматически ставит заданный набор пакетов (по умолчанию: `pyinstaller`, `fonttools`).
- **Прогресс загрузки** — показывает проценты и объём скачанных данных.
- **Чистый выход** — удаляет временные файлы и папку `download` после завершения.

---

## 📋 Требования

| Компонент | Минимум |
|-----------|---------|
| ОС | Windows 7 SP1 / Server 2008 R2 (с PowerShell 3.0+) или новее |
| PowerShell | 5.1+ (рекомендуется) |
| Сеть | Доступ к `www.python.org`, `bootstrap.pypa.io`, `pypi.org` |
| Права | Не требуются права администратора |

## 🚀 Быстрый старт

1. Сохраните содержимое скрипта в файл `get_con.cmd`.
2. Дважды щёлкните по файлу или запустите из командной строки:
   ```cmd
   get_con.cmd
   ```
3. Следуйте инструкциям в консоли:
   - Выберите версию Python из списка.
   - Выберите архитектуру (`amd64` или `win32`).
4. Дождитесь завершения — в папке со скриптом появится каталог `python\` с готовым интерпретатором.

---

## ⚙️ Настройка пакетов

Откройте скрипт и отредактируйте массив `$PACKAGES` в блоке `<resource name="installer.ps1">`:

```powershell
$PACKAGES = @(
    "pyinstaller",
    "fonttools",
    "requests",
    "numpy"
)
```

Если оставить массив пустым (`@()`), будет установлен только `pip`.

## 📁 Структура проекта после установки

```
get_con.cmd
├── download/          ← временная папка (удаляется после успеха)
│   ├── python-3.x.x-embed-amd64.zip
│   └── get-pip.py / pip.whl
└── python/            ← готовый embeddable Python
    ├── python.exe
    ├── python3x._pth  ← автоматически модифицирован для работы pip
    ├── python3x.zip   ← стандартная библиотека
    ├── Lib/
    │   └── site-packages/
    └── ...
```

## 🛡️ Безопасность и ограничения

- Скрипт **не требует** прав администратора и не модифицирует реестр.
- Все загрузки производятся по HTTPS с принудительным TLS 1.2/1.3.
- Проверяется доступность `python.org` перед началом работы (TCP 443).
- **Важно:** не перемещайте и не переименовывайте файл `python3x._pth` после установки — в нём прописан путь к `python3x.zip` со стандартной библиотекой.

---

## 🐛 Известные проблемы

- При использовании **Windows 7** без обновлений TLS 1.2 может потребоваться включить протокол в реестре.
- Некоторые корпоративные прокси могут блокировать `bootstrap.pypa.io`; в этом случае сработает fallback на PyPI wheel.
